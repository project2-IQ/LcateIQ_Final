LocateIQ new_project (XAMPP + MySQL + PHP + Python)
====================================================

1) Start Apache and MySQL in XAMPP.

2) Create the database and tables:
   - Open phpMyAdmin -> Import -> choose: new_project/sql/schema.sql

3) Load location data (LIQ dataset):
   - In browser open: http://localhost/LocateIQ/new_project/tools/import_liq_dataset.php
   - You should see "Imported N rows..."

4) Train the K-Means model (generates ml/models/*.pkl):
   Open Command Prompt:
   cd c:\xampp\htdocs\LocateIQ\new_project\ml
   python -m pip install -r requirements.txt
   python train.py

5) Optional: if Python is not on PATH, set the command in:
   new_project/api/includes/config.local.php
   Example:
   <?php
   return ['python_cmd' => 'C:\\Python312\\python.exe'];

6) Open the app:
   http://localhost/LocateIQ/new_project/

7) Admin user is created in MySQL by schema.sql (or run sql/seed_admin.sql if DB already existed):
   Email: admin@locateiq.com   Password: Admin@123
   Login uses auth/login.php only (no client-side bypass).
   Investors: register via signup (stored in MySQL).

8) After import, delete or protect: tools/import_liq_dataset.php

Default MySQL in config: host 127.0.0.1, user root, empty password, database locateiq.
Override with config.local.php next to includes/config.php if needed.
